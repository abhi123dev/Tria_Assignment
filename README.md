# Contact List

A simple and responsive **Contact List** web app built using **Vite**, **React**, and **Tailwind CSS**.  
The app allows users to **add**, **search**, and **view** contacts easily.

---

## Features

- Add new contacts  
- Search existing contacts  
- View contact details  
- Built with **Vite** for fast development and build  
- Styled using **Tailwind CSS** for a clean and responsive UI  
- Fully responsive design  

---

## Tech Stack

- **Frontend:** React + Vite  
- **Styling:** Tailwind CSS  
- **Icons:** Font Awesome  

---

##  Setup Instructions

Follow these steps to run the project locally:

```bash
# 1️ Clone the repository
git clone https://github.com/abhi123dev/Tria_Assignment
cd contact-manager

# 2️ Install dependencies
npm install

# 3️ Run the development server
npm run dev

# Open Browser and visit 
http://localhost:5173 
```
